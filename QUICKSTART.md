# Quick Start Guide

Get started with AlgoGate in 5 minutes!

## Installation (2 minutes)

### Chrome/Edge/Brave

1. Download or clone this repository
2. Open `chrome://extensions` (or `edge://extensions`, `brave://extensions`)
3. Enable "Developer mode" (top-right toggle)
4. Click "Load unpacked"
5. Select the `algogate` folder
6. Done! 🎉

## First Use (3 minutes)

### Step 1: Check the Extension
- Look for the 🔒 icon in your browser toolbar
- Click it to open the popup
- You should see "Access Blocked" status

### Step 2: Try Accessing Social Media
- Go to youtube.com or instagram.com
- You'll see a beautiful block screen
- This means it's working! 🎯

### Step 3: Solve Your First Problem
1. Click "Go to LeetCode" on the block screen
2. Choose any problem you haven't solved
3. Write and submit a correct solution
4. Wait for "Accepted" verdict
5. See the AlgoGate success notification! ✅

### Step 4: Enjoy Your Access
- Try accessing blocked sites again
- They're now accessible!
- Check the extension popup to see remaining time
- Keep grinding! 💪

## Customize Your Experience

Click the extension icon and adjust:

- **Access Duration**: How long you get after solving (default: 60 min)
- **Grace Period**: Emergency access length (default: 30 min)
- **Blocked Sites**: Add or remove sites (one per line)

Example blocked sites:
```
youtube.com
instagram.com
tiktok.com
twitter.com
reddit.com
```

## Tips & Tricks

### Can't Solve a Problem Right Now?
Use the **Grace Period** button for temporary access!

### Want to Disable Temporarily?
Toggle the extension off in the popup settings.

### Track Your Progress
The popup shows:
- Total problems solved
- Number of blocked sites
- Current access status
- Last problem solved

### Block More Sites
Add any site to the blocked list:
```
netflix.com
9gag.com
pinterest.com
```

## Common Questions

**Q: Can I still use YouTube for coding tutorials?**  
A: Yes! Just solve a problem first, or use the grace period, or temporarily disable the extension.

**Q: What if LeetCode is down?**  
A: Use the grace period for temporary access.

**Q: Can I track problems I solved before installing?**  
A: Not currently - the extension only tracks problems solved while it's active.

**Q: Does this work with LeetCode Premium?**  
A: Yes! Works with all LeetCode problems, premium or free.

**Q: Can I use other coding sites instead of LeetCode?**  
A: Not in v1.0, but it's a great idea for future versions!

## Troubleshooting

### Block Screen Not Showing
- Check if extension is enabled in popup
- Verify site is in your blocked list
- Try reloading the page
- Check browser console for errors

### LeetCode Detection Not Working
- Make sure you're on leetcode.com (not cn.leetcode.com)
- Wait for "Accepted" verdict to appear
- Try refreshing LeetCode page
- Check if extension icon is active

### Settings Not Saving
- Make sure values are in valid ranges
- Check for browser console errors
- Try reopening the popup
